RDCS (Remote Drone Capture System) is a 6 person team project for General Dynamics Mission Systems. RDCS aims to create a deployable,
fast-acting drone capture device that uses a YOLO model to detect and classify a drone, then launching a net to capture the device.
This repository is the team's landing page with info on the project and its team as well as an admin panel for members of the project
to log in and execute commands on the system.
